# دماغ مصري — استوديو إدارة القناة

هذا المجلد هو تطبيق مستقل لإدارة وتشغيل قناة YouTube «دماغ مصري» داخل مستودع `clisutep`. تم الإبقاء على مشروع GitHub CLI الأصلي في `cli-trunk/` دون تعديل.

## ما الذي يقدمه التطبيق؟

يوفر التطبيق لوحة عربية لإدارة أفكار الفيديوهات والسكريبتات والعناوين والأوصاف والكلمات المفتاحية، وسير عمل مرحلي يبدأ من الفكرة وينتهي بالنشر. كما يحتوي على تكامل YouTube OAuth لربط القناة ورفع الفيديوهات وجدولتها بعد تأكيد المستخدم.

## هوية القناة

المحتوى المستهدف باللهجة المصرية ويركز على التكنولوجيا والذكاء الاصطناعي والمعلومات المفيدة. الهوية البصرية والغلاف واللوجو جزء من حزمة القناة، ولا تُرفع أي مفاتيح أو رموز OAuth إلى المستودع.

## الأمان والنشر

تُقرأ مفاتيح Google وبيانات قاعدة البيانات من متغيرات البيئة فقط. لا تضع ملف `.env` أو `client_secret.json` داخل المستودع. قبل النشر يجب مراجعة قائمة حقوق النشر، المحتوى المعاد استخدامه، الموسيقى، الصور، الإفصاح عن المحتوى الاصطناعي، ودقة العنوان والصورة المصغرة.

## تشغيل التطبيق

شغّل أوامر التطوير من داخل هذا المجلد بعد تثبيت Node.js وpnpm. يحتاج التشغيل الكامل إلى متغيرات البيئة الخاصة بالتطبيق وقاعدة البيانات وGoogle OAuth. راجع ملفات الملاحظات الأمنية واختبارات YouTube قبل ربط قناة حقيقية.
