# أتمتة دماغ مصري من GitHub

هذا المسار لا يعتمد على فتح موقع الإدارة. ملف `.github/workflows/damagh-masry.yml` يشغّل العملية من GitHub Actions يدويًا عند الطلب أو يوميًا الساعة 18:00 بتوقيت القاهرة تقريبًا. كل تشغيل يولّد عنوانًا ووصفًا وسكريبتًا باللهجة المصرية من موضوع محدد، ينشئ فيديو Shorts رأسيًا بمقاس 1080×1920 مع تعليق صوتي عربي، ثم يرفعه إلى قناة YouTube بحالة `Private`.

## أسرار المستودع

أضف القيم التالية من إعدادات المستودع في GitHub عبر `Settings → Secrets and variables → Actions → New repository secret`:

| الاسم | الاستخدام |
|---|---|
| `GEMINI_API_KEY` | توليد العنوان والسكريبت والوصف والكلمات المفتاحية عبر Gemini. |
| `GOOGLE_YOUTUBE_CLIENT_ID` | معرّف OAuth لتطبيق Google. |
| `GOOGLE_YOUTUBE_CLIENT_SECRET` | السر المقابل لتطبيق Google. |
| `YOUTUBE_REFRESH_TOKEN` | رمز تحديث OAuth للقناة، ويجب أن يكون صادرًا من حساب قناة دماغ مصري وبصلاحيات YouTube upload. |
| `GEMINI_MODEL` | اختياري؛ القيمة الافتراضية `gemini-2.0-flash`. |

لا تضع أي قيمة سرية في الملفات أو داخل نص الـWorkflow. لا تسجل الرموز في `console.log`، ولا ترفع مجلد `work/` أو ملفات `.env` إلى GitHub.

## التشغيل

من تبويب `Actions` اختر `دماغ مصري - Generate and upload private video` ثم اضغط `Run workflow`. يمكن إدخال موضوع مصري واضح في خانة `topic`. إذا تُركت الخانة فارغة يستخدم التشغيل موضوعًا افتراضيًا. بعد انتهاء التشغيل ستجد الفيديو الناتج وملفات المحتوى داخل Artifact باسم يشبه `damagh-masry-video-12`، كما سيظهر الفيديو في YouTube Studio بحالة Private.

يمكن تعديل العنوان أو السكريبت أو المظهر قبل النشر العام بإعادة تشغيل العملية بموضوع مختلف أو تعديل سكريبتات `automation/`. لا يقوم الـWorkflow بتحويل الفيديو إلى Public تلقائيًا.

## ملاحظات التشغيل

إنشاء الفيديو يعتمد على FFmpeg وespeak-ng المثبتين داخل بيئة GitHub Actions، لذلك لا يحتاج تشغيل جهازك أو إبقاء المتصفح مفتوحًا. جودة الصوت هي صوت عربي آلي مبدئي، ويمكن لاحقًا استبدال خطوة الصوت بمزود صوت احترافي إذا تم توفير مفتاحه. لا تبدأ أي عملية نشر عامة إلا بعد مراجعة الفيديو الخاص يدويًا داخل YouTube Studio.
